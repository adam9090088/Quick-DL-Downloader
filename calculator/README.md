# Quick Calc - Calculator Application

**Created by:** Adam (adam9090088)  
**Version:** 1.0

## Overview

Quick Calc is a modern, fully-functional calculator web application with a beautiful dark theme and smooth animations.

## Features

✨ **User Interface**
- Modern dark theme with gradient backgrounds
- Fully responsive design (desktop, tablet, mobile)
- Smooth animations and hover effects
- Clean, intuitive button layout

🧮 **Functionality**
- Basic arithmetic operations: Addition (+), Subtraction (−), Multiplication (×), Division (÷)
- Modulo operation (%)
- Decimal number support
- Clear button (C) to reset the calculator
- Delete button (DEL) to remove the last character
- Real-time display updates

⌨️ **Keyboard Support**
- Number keys (0-9): Input numbers
- Decimal point (.): Add decimal numbers
- Operators (+, −, ×, ÷, %): Perform calculations
- Enter: Calculate result
- Backspace: Delete last character
- Escape: Clear all

## Files

- **index.html** - Main HTML structure
- **styles.css** - Styling and responsive design
- **script.js** - Calculator logic and keyboard functionality
- **README.md** - This documentation file

## How to Use

1. Open `index.html` in your web browser
2. Click buttons or use your keyboard to enter numbers and operations
3. Press `=` or `Enter` to calculate the result
4. Use `C` to clear or `DEL` to remove the last character

## Technical Details

- **HTML5** - Semantic structure
- **CSS3** - Modern styling with gradients and animations
- **Vanilla JavaScript** - Pure JavaScript, no dependencies
- **Responsive Design** - Works on all screen sizes
